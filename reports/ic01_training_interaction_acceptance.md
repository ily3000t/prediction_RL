| 按原规则复核的条件或交集 | root 数 |
| --- | ---: |
| 宽间距 | 238 |
| 低接近速度 | 238 |

| 有限 TTC 不低于上三分位，或没有接近的有限 TTC | 363 |
| 低 I | 237 |
| 完整共同 5 秒 | 93 |
| 宽间距且低接近速度 | 186 |
| 长剩余距离且低接近速度 | 0 |
| 全部弱 D 条件 | 0 |
| 低 I 且完整共同 5 秒 | 0 |

存在两个独立缺口：弱 D 的条件组合没有交集；低 I 与完整支持没有交集。长剩余距离的 root 来自 approach，低接近速度及宽间距主要来自 internal_mid/downstream。现有采集由参考策略在三个固定近合流位置取得，不覆盖“起步、宽松且剩余距离充足”的完整基础任务集合；后段低响应还常伴随提前终止或自然离开预测观察窗。

这是状态关联、固定 root 位置和有效窗口与分层假设不匹配的证据。不能由此断言原训练任务不存在简单场景，也不能通过放松完整支持、删除困难场景或事后调分位数，把本版报告修成合格。

另有两项定义限制需要任务入口阶段处理：

- 合流前的 target front/rear 间距和 TTC 是公共路线投影代理，不等于已经同车道的实体车身净间距；负投影间距不自动表示真实碰撞。
- C1 的“至多 3 个”是当前选定关键角色车辆数，不是所有交通约束数量；全邻车 CV 冲突代理可达 7。因此目前只能称“关键邻车高响应 root”，不能声称已构成单一约束的可执行训练任务。
