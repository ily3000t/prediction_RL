# RCCI v2 完整既有 cohort：结果复盘与阶段决策

## 结论先行

完整离线运行与结果身份核验通过。较稳健的离线信号是：**B3 的后车最小道路间距
误差小于 B2；前车并非全面改善，完整时域覆盖反而更低。宽合流节点时间/占用
通道主要受 ego 计划及当前占用支配，不宜作为动作条件交互创新的主要证据。**

这不是 Raw vs RCCI 的闭环实验，不能把 B2/B3 差异归功于 RCCI adapter，
也不能宣布策略收益或安全性已提升。建议保留冻结 v2，下一步仅考虑单独批准的
RCCI03 原生接入/语义 smoke，不扩大预测器、不重训预测器、不立即投入正式 DDPG。
不再围绕同一批结果继续调区域/字段/阈值使结果变好。

## 2. 前后道路间距：收益集中在后车，而非全面提高

这里评价 root 到支持终点内、离散样本的**最小 route gap**，不是终点瞬时间距，
也不是连续物理最小净空。使用相同 reference ego，隔离 ego rollout 差异。

原报告固定了两模型/native 的共同时间支持，但某个前后关系的数值可用性仍可能
因预测关系不同而不同，例如 validation front 的 B2=420、B3=424。
因此下表额外取**同候选、同时间支持、双方该数值均可用**的交集。
这是分析层的 complete-case 配对，不修改 adapter 或原报告；未配对和失效数量保留。

### 2.1 validation 其他既有 episode：可变共同前缀

| 指标 | 配对候选 / 有贡献 episodes | B2 ordinary MAE | B3 conditional MAE |
| --- | ---: | ---: | ---: |
| 前车最小 gap，候选池化 | 420 / 35 | 0.2445 m | 0.2999 m |
| 前车最小 gap，episode 等权 | 同上 | 0.2440 m | 0.2783 m |
| 后车最小 gap，候选池化 | 396 / 54 | 0.6370 m | 0.2550 m |
| 后车最小 gap，episode 等权 | 同上 | 0.7292 m | 0.2831 m |

B3 后车候选 MAE 约降低 60.0%，episode 等权也约降低 61.2%；不只是根数量加权
造成的方向。前车候选 MAE 约增加 22.7%，episode 等权仍较差，不能只报后车。

train 的方向一致：前车 0.2191→0.2403 m，后车 0.5949→0.2361 m。
这支持存在后车预测收益，但不证明所有关系、时刻或闭环决策都获益。

### 2.2 validation 固定支持终点：不能以短前缀掩盖长尾

| 支持终点 | 前车配对候选 / episodes | 前车 B2 / B3 MAE（m） | 后车配对候选 / episodes | 后车 B2 / B3 MAE（m） |
| --- | ---: | ---: | ---: | ---: |
| 1 s | 265 / 35 | 0.2104 / 0.0446 | 246 / 54 | 0.0156 / 0.0077 |
| 3 s | 262 / 35 | 0.9406 / 1.2503 | 175 / 52 | 0.2516 / 0.2186 |
| 5 s | 130 / 35 | 0.1113 / 0.1460 | 88 / 35 | 2.1914 / 0.7956 |

B3 前车短时域较好，但 3/5 s 较差；后车 5 s 改善明显，但仍只覆盖 88 个配对候选、
35 个 episode。不同终点的有效候选不同，不能把列间数值当同一样本的误差随时间曲线。

当前状态也可能主导最小值：可变共同前缀后车比较中，B2 有 221、B3 有 222 个
候选的预测最小值在 root。必须保留这一限制，不能把全部最小 gap 指标称为纯未来命中。

## 3. 覆盖与失效：v2 信息保留有效，但不修复预测

validation 其他 episode 的候选总数为 870，其中 root 跨来向关系适用的候选为 600。

| 项目 | B2 | B3 |
| --- | ---: | ---: |
| 完整 5 s following pool | 524/870（60.2%） | 481/870（55.3%） |
| 完整 5 s cross pool | 349/600（58.2%） | 306/600（51.0%） |
| cross 支持内 overlap 描述可用 | 600/600 | 586/600 |
| following 仅 root、无未来支持 | 0/870 | 14/870 |
| actor 首失效为 route reversal | 270 | 344 |
| ego 首失效为有限地图 endpoint | 177 | 177 |

最后两行是重复候选/轨迹诊断计数，不是独立事故。endpoint 均来自相同 ego reference，
不能全归咎于预测器；B3 另有更多 actor 预测倒退，不能因后车误差较小而忽略。
没有 clip/修平/重排轨迹，没有删除坏 actor。

| 固定终点 | 全候选 | native 全池可观察 | B2+B3+native 全池共同支持 |
| --- | ---: | ---: | ---: |
| 1 s | 870 | 824 | 809 |
| 3 s | 870 | 625 | 544 |
| 5 s | 870 | 366 | 183 |

完整 5 s 的严格误差支持只有全部候选的 21.0%，约为 native 可观察候选的一半。
不应将其中的 MAE 推广到剩余未知尾部。v2 允许部分前缀进入描述，不代表完整覆盖
已提升或全部候选已安全。所有 v1/v2 完整支持逐候选相等的守卫仍保持。
root omitted actors 的 validation 中位数为 6.5；这些聚合 token 不是可定位车辆，
不得将接口解释为检查了全场景的每辆车。

## 4. 跨区后果：很容易算得准，但不一定提供新的交互信息

### 4.1 误差结果（原报告的 available-event 条件描述）

| 指标 | B2 | B3 |
| --- | ---: | ---: |
| actor entry MAE | 0.04566 s（1,075 events） | 0.04250 s（1,074 events） |
| actor exit MAE | 0.00599 s（321 events） | 0.00759 s（321 events） |

| actor entry FN / FP | 18 / 8 | 19 / 9 |

事件时间 MAE 以相应双方命中为条件，命中集合未必相同；不能把它们全部当严格相同
事件集的配对提升。entry 漏报/误报没有改善，exit 时间反而较差。时间均为插值后
的有限节点占用描述，不是物理碰撞时间或真实安全裕度。

### 4.2 真正被池化到接口的选中 pair

| 项目 | B2 | B3 |
| --- | ---: | ---: |
| 正 overlap | 595/600 | 585/600（有未来支持者 585/586） |
| 选中 actor 从 root 占用到支持终点 | 494/600 | 481/600 |

B3 最后一项约 95.9%。宽合流节点占用使正 overlap 几乎普遍出现，二值量缺少区分度；
首次重叠往往只是 ego 进入时刻。不能据此声称模型识别了危险、预测了因果让行，
或证明新冲突区域是有效创新。

### 4.3 共同支持下的机制替换

validation，B3；零 jerk 邻车响应作为固定参考，全部模型/五候选使用相同支持。
数值是各自双边有效情况下的平均绝对变化，非可相加的因果贡献比例。

| 通道 | 只改变 ego 计划 | 同 ego 下改变条件邻车响应 |
| --- | ---: | ---: |
| front minimum gap | 2.9172 m | 0.0697 m |
| rear minimum gap | 2.7629 m | 0.2815 m |
| actor entry | 0 s | 0.00875 s |
| first-overlap | 0.02987 s | 0.00140 s |
| overlap duration | 0.04942 s | 0.00138 s |

B3 并非完全没有动作条件信号，尤其后车 gap；但跨区时间通道的变化量主要由 ego
计划驱动。条件响应引起非零 first-overlap/overlap 变化仅在 5/63 个 episode 中出现
（各 16 个候选，数值非零判定 1e-8 s）。不能把它写成普遍存在的交互响应机制。
输入替换可能 OOD，且本分析未检查 DDPG 是否利用这些信息。

## 5. 决策，不再无限诊断

1. **保留 v2 和现有预测器**：后车 gap 有一致离线价值，合法部分支持可供策略学习；
   不要求 B3 所有离线指标全面优胜才能做一次有界闭环探索。
2. **降低论文主张，不改冻结字段**：宽节点占用/时间目前只作上下文及截尾描述，
   不当作核心动作条件机制证据。不按本结果删字段后仍称同一版本；要改需另建契约。
3. **下一步建议 RCCI03，而非正式训练**：单独批准后，明确 native 会话/步数上限，
   验证同一步 observation 的来源/维度/masks、缺失/短前缀和阻塞执行，Raw 默认路径不变。
   当前工作树仍缺 st_cy，须在本工作树单独做构建/资产验收，不改只读基线。
4. **之后才冻结 Raw×RCCI 的匹配 2×2**：先做旧 Raw 模型复用审查，复用不满足就
   明确成本，而不是静默 warm-start。本轮未创建或执行这些训练请求。
5. **明确尚未证明的事**：RCCI 比 Raw 好、条件响应改善实际奖励/到达/碰撞、
   预测摘要是新颖或安全保证。以上仍须闭环与适当对照，不能用本次表格替代。

RCCI02 的完整离线阶段到此结束；不新增 test/泛化/压力 seeds、不升级模型、不再
逐一解释全部失败后才推进，也不自动加大 DDPG 预算。
