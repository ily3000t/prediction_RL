# RCCI04a：静态几何缓存与 Raw 复用审计

2026-10-18，缓存实现与计时前冻结。本阶段是 RCCI04 匹配实验的工程准备，
不授权训练、重新采集、策略评价或改变 RCCI v2 定义。

## 动机与禁止变化

RCCI03 的描述性时延高于 Raw。对已有 18 份 RCCI 原生缓存的零推理 profile
得到 9,841,523 次调用、5.036 s（有 profiler 开销，不能当速度基准）：
`track` 3.874 s、`project` 3.799 s、`zone_interval` 1.070 s。
静态道路折线与相同车身尺寸被重复计算，适合先消除冗余。

- 原 `RoadConsequenceMap`、v2 summary、Raw provider、预测器、DDPG、旧请求守卫不改。
- 新增独立 cached map/provider；不自动替换旧入口，不开放训练。
- 仅缓存不随 observation 改变的折线差分、弧长、累计弧长、平方和总长，以及
  `(root_lane, length_m, width_m)` 对应的控制体积区间。
- 不量化 key、不近似投影、不重排浮点运算、不降精度；不减少 actor、候选或时间点。
- 区间 cache 有界（最多 128 项，LRU）；非法尺寸仍在 lookup 前拒绝。
- 几何状态只读；改变地图须创建新实例，禁止缓存后修改地图导致静默陈旧。
- 相同前缀、mask、无效原因、actor ID/tie-break、缺失值及全部 149 字段必须保持。

## 验证与预算

1. 单元测试覆盖所有车道的投影/端点/异常、不同尺寸、cache 命中/淘汰、只读几何，
   以及 provider 的独立类型与旧入口不变。
2. 复用已封存的 RCCI02 v2 全量 890 roots × B2/B3 = 1,780 个均值预测，
   与其原始 `v2_features` 和全部 `v2_candidates` 精确比较。
3. 复用 RCCI03 的 18 份 RCCI history/mean/ego 缓存，与原生特征精确比较；
   同时用未改原 map 重算完整 summary，比较全部字段。
4. 不加载预测器/策略，不执行 model forward，不连接 SUMO，不更新权重/随机状态。
   历史证据原始文件和哈希必须验证，不放宽或重跑旧 source/HEAD 守卫。
5. 描述性计时仅用这 18 个缓存输入：先各实现 warmup 一轮，再交替顺序执行
   3 轮，记录两实现各 54 个样本的 mean/p50/p95/p99/max。精确比较后才报速度。
   不以加速比作为通过条件，不作为部署实时性或新场景方法效果结论。
6. 新目录、干净已提交源码、resolved config/commit/环境/输入输出哈希、一次写入与
   失败留存；旧产物不覆盖。全量是缓存重算，不新增 890 个仿真或独立场景。

## Raw 复用审计（只读）

候选来源是只读基线 `75051acc` 的 `artifacts/p7n/p7n_120k_v1`：
B2 ordinary、B3 conditional，各 seeds 0/1/2；主终点是固定 120k 节点。

- 检查冻结请求、聚合及 receipt、六个训练 receipt/权重、相应已完成评价的完整性。
- 比较预测器、特征/网络/训练预算、奖励/动作/终止/执行契约、环境和源码身份。
- checkpoint 仅作为历史 Raw 对照候选，绝不加载成同维 RCCI 权重，不作为训练续点。
- 旧与当前原生扩展 SHA 不同，文本可能仅换行不同；必须分别记录字节身份与语义
  核查范围，不能默认相等、改旧 metadata，或无依据要求重训六个 Raw。
- 区分“历史证据完整”“严格环境身份相同”“可用于未来匹配对照”。最后一项若有
  未解决差异，保持待审批；本阶段不启动策略交叉评价来补齐它。
