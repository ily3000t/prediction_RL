## 2. 研究问题与贡献边界

本研究优先回答：同一个冻结预测器、相同连续 DDPG 和原奖励下，将稀疏世界坐标摘要改为道路关系一致的候选后果，能否改善策略对预测的利用？

需要分开判断：

1. 道路后果接口是否普遍改善 B2/B3；
2. 新接口是否保留了 B3 相对 B2 的动作条件信息增量；
3. 变化主要来自道路/地图先验、完整时域事件提取，还是动作条件邻车响应。

不能以“加入 TTC”“预测占用辅助 RL”“使用候选动作或图结构”单独宣称创新。潜在贡献应限定为可验证的接口机制及匹配实证；不预设能够发表、优于所有方法或取得安全保证。

## 3. 已核实的当前接口

直接来源为 `src/prediction_rl/features/probe_features.py`、`prediction/model.py`、`prediction/interface.py`、`prediction/candidate_ranking.py` 和 `data/merge_geometry.py`。

- 原观测前缀不变，预测摘要共 149 维：120 个相对状态、20 个池化距离、9 个当前有效性/历史覆盖通道。
- 五个探针的首步 jerk 为 -5、-2.5、0、2.5、5；作用一个原始 0.2 秒周期，之后 24 步为零 jerk 参考控制，不是重复执行首步动作。
- 预测器输出 25 个未来时刻，但当前摘要只取 0.2、1、3、5 秒。
- 前/后角色的 dx、dy 是固定 root 原点下的世界轴位置差，池化距离是车辆参考点欧氏距离，不是道路净距。
- 当前 provider 先取三成员平均轨迹，再算摘要；模型已另行输出 `member_trajectories` 和 disagreement。
- 预测输出没有未来 lane ID。原 `MergeGeometry` 只支持已审计五 lane 链；其跨路径 ETA 差和道路 progress 不能直接当作一般物理碰撞时间。
- 虽然计划校验允许合法连续首步 jerk，原自车 `rollout_ego` 严格要求五个固定探针；不得直接替换数值声称支持策略附近任意探针。

上述是可研究的表示限制，不是已经证明的性能根因。RCCI 不重复已经完成的 reward、终止和 replay 基础工程审计；只核查新接口引入的影响。

## 5. 路线 A：道路关系一致的候选后果

### 5.1 处理位置

在预测输出与策略观测之间增加独立、版本化的 RCCI adapter。第一版优先确定性变换，不同时增加 GNN/Transformer。保持原 Raw provider 和默认路径不变，不修改共享预测器或旧 checkpoint contract。

输入白名单：当前可观测历史、稳定 actor ID、原 masks、已知地图及可合法获得的路径、冻结预测输出、原探针自车 rollout。真实未来、未来存在 mask、原生结束原因、标签和回报只能用于离线评价，不进入在线特征。

### 5.2 表示单元与初步字段

以“候选 × 可定位物理 actor × 道路关系/共同冲突区域”为基础单元，再按冻结规则压缩成定长观测。字段是设计提案，具体布局、尺度、聚合与版本号在 RCCI02 前冻结，不能依据闭环评价结果反复选择。

| 部分 | 候选字段 | 必须区分的语义 |
| --- | --- | --- |
| 道路关系 | 同路径、跨路径共享冲突区域、无直接冲突关系 | 距离近不等于存在路径冲突 |
| 同路径后果 | 有符号前/后净距、接近速度、预测最小净距及发生时间 | 保留方向与车辆 extent，不用欧氏点距冒充 bumper gap |
| 冲突区域后果 | ego/actor 的进入和离开时间、占用窗口 | 根据路径与车辆几何定义区域，不直接使用合流终点 ETA 替代 |
| 交互后果 | 时间窗重叠、通过次序、时间裕度 | 同时保留连续量，不只输出先/后离散标签 |
| 有效性 | 关系不适用、未在时域内到达、投影歧义/失败、历史不足 | 不到达不等于安全，不可计算不等于零风险 |

可以额外描述相对零 jerk 参考候选的后果差，但必须保留绝对后果及双方有效性；这只是特征变换，不是恢复差分监督。

### 5.3 地图与时域约束

- 核查 SUMO 位置参考点、车辆长宽、道路切向与 lane 链，不能未经验证假定参考点为车身中心。
- 在共同 root 原点、地图与预测坐标之间显式变换。道路投影只使用合法路径；不能将离路/歧义预测强行吸附成安全道路状态，不能根据未来真值选择投影分支。
- 使用完整 25 点轨迹提取事件，不扩展原时域。边界交叉插值、车辆占用及采样漏检假设要记录并验证；描述特征不构成连续时间安全证明。
- “超过 5 秒未到达”作为时域截尾单独编码；不能填入任意巨大 ETA 或将其误作已观测安全间隙。
- 原 mandatory actor ID 和 masks 保留。后果池化可遍历原物理 slots，候选中的关键角色可变化，但规则只能依赖当前/预测信息并有稳定 ID tie-break。
- omitted summary token 不是一辆可定位车辆，不能为其伪造轨迹或声称精确检查了所有遗漏车辆。继续报告容量和关键 actor 覆盖。
- 合法缺失量使用数值占位加独立 mask；NaN、维度错误、模型加载失败等工程错误必须显式使运行无效，不能静默归为正常缺失或安全。

## 6. 先做离线可行性核查，不先重训策略

仅复用已冻结 train/validation 数据，按 episode/root 分组；不打开独立 test，也不根据场景 200–219 的方法输赢设计接口或阈值。新产物须使用本工作树下独立短 run ID，不覆盖历史请求/报告。

应回答：

1. 地图投影、冲突窗口和通过次序是否可稳定计算，哪些情况不可计算，覆盖率是多少？
2. 新后果量相对原生几何标签的误差、事件识别和次序判断如何？要同时检查偏差、漏检、截尾与有效支持，不以单一平均 loss 判断。
3. B2/B3 的候选后果差中，哪些只来自 ego 计划，哪些确实来自邻车响应？可在纯离线诊断中固定邻车参考响应再重建摘要，但替换可能 OOD，敏感性不能独立证明正确利用信息。
4. 四时刻摘要是否遗漏短暂事件？平均轨迹前/后提取后果是否会改变判断？不能预设答案为肯定。

工程核查覆盖坐标/单位一致性、稳定 ID、同路径与跨路径边界、footprint、缺失/截尾 masks、批量与逐候选一致性、adapter 的共同刚体坐标变换一致性。该一致性只针对地图/轨迹后处理，不能强迫原预测网络具有未经训练的旋转等变性。

离线指标不要求 B3 全面战胜所有参考才允许有界闭环探索；但若大量关键后果不可计算、候选差主要为坐标伪差或预测错误，应先修正定义，不直接投入昂贵 DDPG。合法负结果正常完成聚合，不降低标准或删除样本。

## 8. 路线 B：可选成员级后果聚合

仅在 A 的证据审阅后另行决定，不与第一版同时默认加入。区别是先对每个成员的完整场景预测计算后果，再聚合，而不是先平均轨迹再计算非线性后果。

候选信息包括后果均值/离散程度、占用重叠分歧、通过次序一致性和候选后果排序一致性。保持同一成员内部的多 actor/候选对应关系，不能随意拼接不同成员形成貌似可信的联合未来。B2/B3 使用相同方法。

三成员分歧不是完整多模态分布；成员占比不自动等于真实概率，也不提供已校准置信区间、CVaR 或安全保证。若分歧几乎不改变后果或不对应误差，不投入额外一轮训练。增加 B 时须将 A-only 与 A+B 区分，不将两个变量合成一个无法解释的增量。

## 9. 路线 C 与其他暂不实施项

动作条件 critic、策略附近连续探针、任务事件辅助监督、学习式图 adapter 均为后备，不在 RCCI 第一版范围。

特别是 `Q(s,a,z(s,a))` 将涉及连续动作支持、原固定 rollout、replay 历史上下文和策略梯度链；冻结模型参数不等于切断动作梯度。不能原样沿用 inference_mode/detach/NumPy 后处理，也不能把参考后续下的短期后果冒充真实 Q^pi。

当前不修改预测器、loss、数据采集、奖励、动作、算法或场景来补救结果；不恢复已归档差分/课程线，不自动加入作者 50 秒协议、泛化、压力场景或 deployment-runtime 实验。

## 11. 与文献的关系及阅读顺序

以下是研究定位，不代表这些方法已在本机复现或已穷尽所有相关工作：

1. [ROSA-RL，ITSC 2026](https://arxiv.org/html/2606.16558v1)：冲突区域占用预测增强 RL；[作者仓库](https://github.com/urbanAIthi/ROSA-RL)。RCCI 不能只以冲突区域 + RL 宣称创新。
2. [MATS，CoRL 2020](https://proceedings.mlr.press/v155/ivanovic21a.html)：研究适合下游规划/控制的预测表示，说明接口是合理问题，但不是空白领域。
3. [Predictive-Decision，ITSC 2023](https://arxiv.org/abs/2302.03939)：自车计划条件下的邻车响应预测 + 采样规划；[作者仓库](https://github.com/MCZhi/Predictive-Decision)。其规划器不能与连续 DDPG 混为同类。
4. [GP3Net，AAAI 2024](https://ojs.aaai.org/index.php/AAAI/article/view/29043)：未来占用图输入 PPO，使用 CARLA；不能将轨迹转占用再辅助 RL 当作首次。
5. [BeTop，NeurIPS 2024](https://papers.nips.cc/paper_files/paper/2024/hash/a862f5788fd09bb6843c694d8120d50c-Abstract-Conference.html)：行为拓扑连接预测与规划；[公开仓库](https://github.com/OpenDriveLab/BeTop) 明确提供 WOMD 预测部分，不据此假定完整规划流程已可复现。
6. [TIP，IROS 2022](https://arxiv.org/abs/2110.08750)：预测准确性与任务效用不等价，不能仅靠 ADE/MSE 选择研究路线。
7. [DTPP，ICRA 2024](https://github.com/MCZhi/DTPP)：联合条件预测与代价评价，是后备 critic 路线需要比较的规划类先例，不是现有 DDPG 的直接替换。
8. [Interventional Behavior Prediction，IROS 2022](https://arxiv.org/abs/2204.08665)：条件预测不自动等于可信干预预测。现有同 root 分叉有助于刻画限定 SUMO 干预，但不证明真实世界因果安全性。
