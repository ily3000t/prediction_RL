研究问题：课程是否提高样本效率、减少训练种子波动，以及是否特别有助于利用动作条件预测，而不只是帮助所有策略。

普通与条件预测使用各自已验证的冻结权重。改变任务分布会改变策略经历的状态，这是课程的预期作用；**环境重启、预热、插入位置或历史恢复方式的改变则是另一项训练协议变化，不能藏在课程开关下。**

当前历史 B3 在 20 个反复使用的开发场景、三个训练种子的 120k 节点已取得 60/60 自然到达。新的重点应是早期效率、稳定性及最终安全/舒适性保留，不应预设还能提高已饱和的最终到达率。

## 4. 首要缺口：从 root 交互到可执行 task

应分开保存两类实体：

1. `root_record`：同一历史状态及候选分支的 D/I 统计，是离线证据。
2. `task_record`：环境能在批准的 episode 边界进入的训练任务，有生成参数、seed、入口协议和固定分层依据。

多个 root 来自同一 episode，不能作为独立任务或独立交通场景计数。必须在训练前冻结 root 到 task 的映射、参考控制器、道路检查位置、不可达 root 的处理及一个 task 含多 root 时的聚合规则。不能用当前正在学习的 B3 表现决定 task 所属层。

现有连续训练没有任意任务入口。因此 IC02 必须先选择并核验实现路线：

- 优先：在现有合法入口内构造可辨识任务，且证明分层对象与实际进入的状态一致，不跳过回合、不反复 reset 拒收场景、不中途修改交通。只改变已有随机量的采样，也需明确记录其分布变化。
- 如果做不到：提出**独立命名的新训练任务入口协议**，由用户确认后用于四组。重启、参考前缀、保存恢复或多持续上下文都不是旧 reset 的同义写法；必须记录各自的随机流、交通时间、历史长度及控制责任。
- 参考前缀耗时、自车是否已处于任务中段、剩余期限及预测历史变化不能当作免费初始化或隐去。若使用新入口，应明确计费/预算与可比范围后再冻结。

不能未经验收就选某种入口实现。原 B3 可作历史参照；新入口下必须重训 B2-Mix/B3-Mix，不用旧 B3 替代匹配对照。

## 5. D/I 核查及互斥分层

### 5.1 D：当前可观测控制约束

记录道路坐标下前后有效间距、接近速度、有限性明确的冲突时间代理、剩余合流距离及关键车辆数。分量分别保留，不随意加权成一个分数。不存在前后车、非接近状态及 TTC 为无穷的情况分别编码，不能使用任意有限替代值改变分位数。

关键车辆规则只使用 root 当前状态、道路关系及冻结的计划几何定义。邻车集合在候选之间固定，通过车辆 ID 对齐；不依据哪个分支成功、哪个方法胜出或未来最近距离来事后选择车辆。

### 5.2 I：真正的邻车响应

只对同 root 的候选对、关键邻车及共同有效时刻计算响应差。排除 ego；固定 `c_v`、`c_x`、道路投影、候选对权重、时间权重及最小可用支持规则。

现有共同 root 原点可以消除候选自车移动造成的坐标偏差，但 root-relative x 并不自动等于沿弯道的道路纵坐标。道路 sidecar 必须沿一致的路线/冲突链投影，不能在车辆换 edge 时直接相减局部 lanePosition。误差检查应比较共同坐标下的真实邻车轨迹，而不是 ego-neighbor 间距。

同动作重复分支用于估计同一指标的噪声下限。不同候选的 I 必须高于该下限。需一并报告可用候选对、有效车辆/时刻数、共同覆盖时长、actor 消失与终止截尾。不允许截尾被掩盖成低 I，也不能以重复分支作为新增训练样本。

分层与归一化仅使用已冻结的 train split，不打开 test，不用 200-219 开发结果制定阈值。IC01 的开发规则在分析前提交，随后从 train root 计算待审核分位数边界，实际数值保存在不可覆盖的报告中；它们不是最终 task 阈值。大量零响应时，不能把零值的上分位数直接解释成明确交互，也不能在看到空层后直接放宽原规则。

### 5.3 分层与暂停条件

- C0：满足预先冻结的弱控制约束规则，并有可计算且较低的 I。
- C1：满足预先冻结的关键交互规则，I 明显高于重复噪声且共同支持合格。
- C2：其余完整合法任务，包括困难但低交互、难以归类及 I 暂不可计算的情况；另存不可计算原因。

确定规则优先级，使每个合法 task 恰好分入一层。不可达 root、工程错误和缺失审计不能直接冒充正常 C2 样本；必须单独记录，且不按策略失败或碰撞删除合法任务。

IC01 发现 211 个符合暂定 C1 的 root，来自 181 个源 episode；这不是 211 个独立任务，也没有证明它们能通过合法任务入口执行。C0 为零：长剩余距离与低接近速度条件无交集，低 I 与完整共同时域也无交集。旧数据只覆盖参考策略沿途的三个近合流位置，不能用其 root 比例直接定义目标任务分布。IC02 必须先核查任务入口与完整覆盖；不通过时暂停训练，不通过换阈值让分层看起来合格。

## 6. 调度与 Mix 对照

| 累计实际控制交互步数 | C0 | C1 | C2 |
| --- | --- | --- | --- |
| 0-20k | 0.60 | 0.30 | 0.10 |
| 20-60k | 0.20 | 0.60 | 0.20 |
| 60-100k | 0.10 | 0.30 | 0.60 |
| 100-120k | pi0 | pi1 | pi2 |

`pi` 是原目标任务分布，尚待定义和测量，不能默认为三层等比例，也不能用开发评价场景替代训练目标分布。初始三阶段比例按本设计提议保留；任务池可行性未通过前，不把它们包装成已验证最优比例。

Mix 的名义 reset 采样比例应为：

```text
pbar(C0) = 0.20     + pi0 / 6
pbar(C1) = 0.35     + pi1 / 6
pbar(C2) = 17 / 60  + pi2 / 6
```

这是按 20k、40k、40k、20k 阶段步长得到的计划比例，**不是实际 transition 曝光等价的证明**。episode 长度、策略结果、阶段超出步数及 replay 滞后均会造成偏差。统一任务池、任务内采样规则与相应 seed，报告每层 task 次数、环境交互步数、完成/失败次数及实际超出步数。差异明显时只称“课程调度与匹配名义配额的随机混合比较”，不称纯粹训练顺序的因果效应。

调度使用独立、显式记录的 RNG，不改变网络初始化、探索噪声或交通生成 RNG。阶段依据审计的实际控制 transition 计数，而非墙钟、评价回合、SUMO 预热 tick 或 reset 伪 transition。达到边界后当前 episode 继续，下一次合法 reset 才变更任务采样；记录请求节点、ALL frame、实际控制步和实际切换点。

## 7. replay：保持算法，观察真实更新分布

保留原 replay 容量 1,000,000、均匀采样、batch 100、warmup 5,000、学习率 0.0002 及既有更新/target/noise 配置。阶段切换不清空 replay、不重置优化器、不重排插入、不优先回放 C1。

课程元数据由外部审计按 transition ID 关联：task_id、level、collection_stage、actual_environment_step；不追加到 observation/TimeFeature，不修改 reward/action，不用额外随机抽样估计真实 minibatch。

报告近期采集、当前 replay 存量、真正抽取的 minibatch 三种分布。120k 小于 replay 容量，早期样本通常不会被淘汰；最后 20k 原目标分布的 transition 在最终存量中仅约占六分之一。因此该阶段是“重新接触原目标任务”，**不能保证更新分布已经回到原分布或消除课程偏置**。第一版通过实测记录解释此限制，不额外修改 replay 算法。

## 8. 匹配实验与评价

四组：B2-Mix、B2-Curriculum、B3-Mix、B3-Curriculum；训练种子 0/1/2，全部从头训练，每模型 120k 请求步。共 12 个模型、1.44M 请求步，既有 episode-boundary 超出步数另外记录。不得从 `n120000.pt` 冒充完整 optimizer/replay/RNG 断点续训。

冻结评价节点 20k/40k/60k/120k，开发评价保持 `gym20_fresh_process_first_episode` 与 200-219 的 20 个场景。共 960 回合，是 20 个交通场景、三个训练种子的重复评价，不是 960 个独立场景。主终点为 120k，无最佳节点事后选择，无自动加预算；不新增 author50 或泛化实验。

主表：原回报、自然到达、碰撞、期限失败、平均绝对 jerk、关键前后间距，及每个训练 seed。记录低速停滞、动作饱和与从退化恢复的情况。早期效率以冻结开发评价曲线展示，训练 episode return 不替代验证。

20k-120k AUC 如采用非等距节点的梯形积分，必须标注为“节点近似 AUC”，按区间宽度归一化，不推断未评价节点的连续表现。性能阈值如使用，需事先固定，并只报告相邻评价节点所限定的达到步数范围。seed 离散程度逐节点给出；三个训练 seed 不足以夸大稳定性或显著性。

动作条件特异性使用预先规定的差中之差：

```text
G = (R_B3,Curr - R_B2,Curr) - (R_B3,Mix - R_B2,Mix)
```

同时报告到达、碰撞、jerk 的增量，保留 training seed 与 simulator scene 两层配对；不将多个节点、候选或时间步当作独立重复。G 为正但安全或舒适性明显退化，不支持替换原 B3。

## 9. 信息利用：有限、离线的机制诊断

在预先规定的道路位置/时刻采样，不仅选成功或失败回合。使用冻结策略比较原 B3 特征与“所有候选邻车响应统一为零 jerk 参考候选响应”的重建特征。保留每个候选原自车计划和原摘要计算流程，不删除整张候选表，不加入新通道，不用真实未来在线改动作。

记录连续 jerk 变化、交互层与训练节点。替换可能是 OOD，敏感性不证明利用正确；该诊断与最终闭环结果联合解释。第一版不额外开启一套闭环特征消融。

## 11. 相关研究与贡献界限

[CM3](https://arxiv.org/abs/1809.05188) 将单体目标学习与多体合作分阶段处理；[Curriculum RL via Constrained Optimal Transport](https://proceedings.mlr.press/v162/klink22a.html) 从任务分布之间的插值与约束运输构造课程。这些是课程与交互学习的研究基础，不是本方案三层规则、固定比例或单体 DDPG 对比的验证证据。

本轮潜在贡献是：以**可辨识且任务相关的邻车响应差异**组织任务，并检验课程是否提高动作条件信息的利用效率。不能仅以“采用课程学习”宣称新颖，也不能以 B3-Curriculum 独自提高就声称动作条件特异性；须由四组匹配对照及机制证据支持。
