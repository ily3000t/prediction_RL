# P7l：统一 Gym20 外部基线比较

## 阶段目标与前置条件

完成 P7k 60k 结果核验后，先比较冻结作者控制器，不训练或修改模型。
本阶段不是 Author50 复现，也不批准 120k、P8 或预测网络升级。

## 范围

新增独立适配器、协议、执行器、单元测试和运行文档。
不修改上游、P7k 执行源码、历史配置、模型、结果或旧 ACCVP 项目。
作者 DDPG 保留连续 jerk；ST 与 safety/switching RL+MPC 保留原速度执行、
虚拟策略查询和接管逻辑，不转换或裁剪成 jerk 动作。

## 验收

- 单元测试验证奖励适用边界、无额外步进、协议冻结、配对统计与负结果完成。
- 场景 200：四作者控制器各一次无 observer 参考及一次带 observer 重放，共最多八回合。
- 命令、实际状态、回报、结束事件、策略查询次数和接管序列完全一致。
- 复用已有 60k 的 B0–B3、全部三个种子，不重新仿真或挑选 checkpoint。
- 全 20 场景评价由用户启动。失败产物不可自动覆盖；只允许已完整验证回合的 resume。

## 产物与 Git

产物位于短路径 `artifacts/p7l/<run_id>`；大文件与权重不进入 Git。
功能分支 `codex/p07l-gym20-external-comparison`，实现/测试与验收文档分原子提交。
不推送上游源码，不新增可运行里程碑 tag。

## 暂停条件与交接

适配 parity、原始事件或共同初始场景不一致时停止，不放宽标准。
方法效果为负不导致工程 gate 失败。
执行命令见 `docs/runbooks/p07l_gym20_external.md`。
