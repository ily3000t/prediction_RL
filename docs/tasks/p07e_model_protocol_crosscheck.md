# P7e 模型来源 × 评价协议交叉检查

## 目标与前置条件

先解释作者预训练DDPG与本项目20k步DDPG的来源/协议差别，再讨论噪声诊断。
复用完整P7、P7d及其模型绑定，旧P7b的6/9仅是三个诊断场景×三个训练种子；
完整P7无预测模型为40/60，不能与另一作者权重的20/20直接称为矛盾。

## 允许及禁止范围

仅添加独立协议、评价入口、统计、测试与文档。旧执行文件、配置、请求、结果、
checkpoint、作者源文件保持不变。不训练、不选checkpoint、不改奖励、不接ST。
旧E:/WCDT_ACCVP只读，封存test不开放，不推送未经许可的作者源码或权重。

## 实现任务

- 新增作者预训练模型在P7 Gym20的20回合。
- 新增本项目B0三个最终checkpoint在P7d author50的60回合。
- 已验证的另200回合只引用，不重跑、不复制改名为新证据。
- 同协议内按场景配对；跨协议仅报告原口径事件敏感性，不计算奖励差。
- 固定观测、TimeFeature、连续jerk、终止及冻结模型审计。
- 完整、无效和负结果分开；失败/半成品保留，禁止自动重试或换seed。

## 测试与验收

单元测试覆盖完整模型加载、输入布局、一个实际步一个时间推进、终止重置、
协议内交通一致性、同checkpoint跨协议绑定、缺失/重复/异常结果拒绝。
场景200工程验收只运行四个新增组合，上限500+3×501=2003次实际控制调用。
每个动作同时与不推进TimeFeature的原策略直接forward精确比较。
这些是实际轨迹上的输入/动作/时间接口审计，不是独立双实现整回合复现证明。
工程验收不要求成功到达，碰撞与停车仍是合法负结果。

## 产物、Git及暂停条件

产物只在artifacts/p7e/<短run-id>；配置、脚本、测试与小型验收报告进入Git。
codex/分支上原子提交，完整审查后非squash合并；不推送。
历史文件变化、来源不明、输入/动作/时间不一致或完整收据缺失时暂停，
不放宽契约。正式80回合由用户启动；结果差不构成工程失败。
